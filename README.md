# HII_Regions_AMUSING
This repository contains data products derived for the HII regions of the 41 galaxies sample used to study their luminosity functions, from the AMUSING (+/++) sample.

The data folder contains:
a) General: the full catalog with the characterization of the ~12,000 HII regions of the full sample, as well as general information of each galaxy.
b) Per galaxy: the FITS files of both H alpha emission-measure map and HII region segmentation map, and the catalog of extinction-corrected emission-line fluxes for their HII regions, normalized by H beta.
